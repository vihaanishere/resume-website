# Vihaan Lawania - Portfolio Website

A personal portfolio website showcasing my projects, skills, and experience.

## 🚀 About

This is my personal portfolio website built with HTML, CSS, and JavaScript. It features a clean, modern design with a dark theme and showcases my work as an AI/ML student and aspiring full-stack developer.

## 📋 Sections

- **Home** - Hero section with introduction
- **About** - Brief overview of who I am
- **Skills** - Technologies and tools I work with
- **Projects** - Showcase of my work
- **Contact** - Ways to get in touch

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (coming soon)

## 🎨 Features

- Responsive design
- Dark theme
- Clean and modern UI
- Easy navigation
